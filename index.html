Shortcuts for Buttons

  • Home for Menu
  • Shift + PgDn for Plot
  • Shift + PgUp for Trace
  • Ctl + Shift + A for Alpha
  • Ctl + Shift + C for Cos
  • Ctl + Shift + D for Mode
  • Ctl + Shift + F for f(x)
  • Ctl + Shift + L for Ln
  • Ctl + Shift + M for Matrix
  • Ctl + Shift + P for π
  • Ctl + Shift + Q for Etc
  • Ctl + Shift + R for √
  • Ctl + Shift + S for Sin
  • Ctl + Shift + Y for Tan
  • Ctl + Shift + U for Stat

About

This is an emulator for a calculator I'm developing. The calculator only works with keyboard input (no support for mouse input). Typing in the letters sin will be interpreted as s*i*n. The Sin button must be activated in order for sin to represent the sine function.
